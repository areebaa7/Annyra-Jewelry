# 💎 Annyra Jewels: Luxury Jewelry Catalog

A responsive catalog and landing page for a fine jewelry brand, with category filtering, product sorting and polished page transitions.

## 🛠️ Tech stack
React · React Router · Vite · Tailwind CSS · Framer Motion · JavaScript (ES6+)

## ✨ Features
- Dynamic category filtering and interactive sorting across seven categories: Bangles, Bracelets, Brooches, Earrings, Pendants, Rings, Sets
- Inventory rendering is automated, so new product images appear without manual wiring
- Reusable components: auto-running testimonial carousel, circular category navigation, multi-column footer, social gallery
- Page transitions and micro-interactions with Framer Motion
- Responsive on mobile, tablet and desktop
